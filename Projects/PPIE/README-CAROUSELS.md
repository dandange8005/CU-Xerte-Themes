# PPIE Carousel Implementations

This directory contains **three versions** of the PPIE Schools carousel, each with different features and capabilities.

## 🎯 Three Versions Available

### 1. **JavaScript Version** (Recommended ⭐)
- **File**: `Homepage-carousel.html`
- **Features**: Full-featured Netflix-style carousel
- **Navigation**: Buttons, drag, keyboard, scroll wheel, touch, dots
- **Best for**: Production use, best UX

### 2. **CSS-Only Version**
- **File**: `Homepage-carousel-css-only.html`
- **Features**: Basic carousel, no JavaScript
- **Navigation**: Anchor links, scroll, touch, radio buttons
- **Best for**: JS-restricted environments

### 3. **Original Grid** (Backup)
- **File**: `Homepage-backup.html`
- **Features**: Traditional CSS Grid layout
- **Best for**: Fallback, non-carousel view

## 🚀 Quick Start

### To Use JavaScript Version (Recommended):
1. Open `Homepage-carousel.html` in browser
2. Try all navigation methods:
   - Click arrow buttons ◀ ▶
   - Click indicator dots ● ○ ○
   - Drag with mouse 🖱️
   - Use arrow keys ⌨️
   - Hold Shift + scroll 🎡
   - Touch swipe 👆

### To Use CSS-Only Version:
1. Open `Homepage-carousel-css-only.html` in browser
2. Available navigation:
   - Click arrow buttons (jumps via anchors)
   - Click radio button indicators
   - Natural scroll
   - Touch swipe

### To Use Original Grid:
1. Open `Homepage-backup.html` in browser
2. All cards visible in grid layout

## 🎯 Which Should You Use?

### Use JavaScript Version If:
- You want the **best user experience**
- You need **full accessibility**
- You want **drag and keyboard** support
- JavaScript is acceptable

**→ This is the recommended version for production**

### Use CSS-Only Version If:
- JavaScript is **not allowed**
- You need **absolute simplicity**
- You're okay with **limited features**

### Use Original Grid If:
- You want **all cards visible** at once
- You prefer **traditional layout**
- You want **no carousel** functionality
